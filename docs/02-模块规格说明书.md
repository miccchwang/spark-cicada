## M-FILTER · 筛选与时间模块

| 项 | 内容 |
|---|---|
| 语言 | TypeScript |
| 职责 | 提供**唯一**的筛选状态编辑入口；产出 `QueryState` |
| 输入 | 用户交互（滑块、下拉、chips、日历、搜索框） |
| 输出 | `QueryState`（纯 JSON，可序列化） |
| 依赖 | `contracts/query-state.ts` |
| **禁止** | 不查库、不发请求、不渲染业务数据、不含业务公式 |

**子组件**

| 组件 | 说明 |
|---|---|
| TimeSlider | 时间区间滑块（preset / custom / slider 三模式） |
| GrainPicker | 粒度选择（日/周/月/季/半年/年） |
| DimensionFilter | 维度筛选（品牌/渠道/店铺/品类…） |
| TableFilter | 表格列筛选（字段 + 操作符 + 值） |
| SortClause | 排序 |
| ResetButton | 一键复位（清空全部选择属性，不动视图偏好） |

**验收**
- [ ] 任何界面形态产出的都是同一个 `QueryState` 结构
- [ ] 状态可 JSON 往返（serialize → parse → 深度相等）
- [ ] 无网络调用、无 DOM 查询副作用
- [ ] 拖动滑块时通过 WASM 本地即时反馈（§11.2）

## M-QUERY · 查询编排模块

| 项 | 内容 |
|---|---|
| 语言 | Go |
| 职责 | `QueryState` → 查询计划 → DB → `ResultSet` |
| 输入 | `QueryState` |
| 输出 | `ResultSet` |
| 依赖 | DB、Redis（缓存）、`M-PRECOMP`（桶元数据） |
| **禁止** | 不含业务公式；不决定"该显示什么" |

**逻辑**
1. 规范化 `QueryState` → 计算 `queryHash`
2. 查 Redis 缓存（键 = §11.3）
3. 未命中 → 选择最优预计算桶（`precomputeHint` 或规则匹配）
4. 生成 SQL（过滤下推、排序下推、分页下推）
5. 结果写入缓存 → 返回 `ResultSet`

**验收**
- [ ] 相同 `QueryState` 必得相同 `ResultSet`（幂等）
- [ ] 命中预计算桶时 P95 < 100ms
- [ ] 无缓存时的查询计划可解释（EXPLAIN 输出可读）

## M-ALGO · 算法注册模块

| 项 | 内容 |
|---|---|
| 语言 | Rust |
| 职责 | 加载 `algorithms/*.yaml`，编译为可执行法则，提供执行与追溯 |
| 输入 | 算法定义（YAML） + 数据（来自数据槽） |
| 输出 | 计算结果 + `AlgoTrace` |
| 依赖 | `M-RULE`、数据槽注册表 |
| **核心约束** | 算法只声明**公式**与**依赖槽**；数据来源由槽定义，两者分离 |

**算法定义契约**

```yaml
id: string                # 唯一 ID，如 algo.gp
name: string              # 中文名
version: int              # 升版本触发桶重算
formula: string           # 纯公式，不含数据源
unit: string              # 单位
permission: L1..L4
depends_on_slots: [string]
writes_bucket: string
missing_policy: skip      # skip | null | error
trace: bool
```

**验收**
- [ ] 每条算法可独立单测（给定输入 → 期望输出）
- [ ] 数据槽缺失时行为符合 `missing_policy`（默认 skip，不补 0）
- [ ] 所有输出可沿 `AlgoTrace` 回溯

## M-PRECOMP · 预计算模块

| 项 | 内容 |
|---|---|
| 语言 | Rust + SQL |
| 职责 | 按算法产出的桶定义，把结果物化到 DB；增量刷新；版本管理 |
| 输入 | 算法 + 规则 + 数据 |
| 输出 | 预计算表（物化视图 / 物理表） |
| 依赖 | `M-ALGO`、`M-RULE`、DB |

**桶定义契约**

```yaml
id: pnl_month
grain: [month, channel_code, shop_id, brand]
produced_by: [algo.rev, algo.cogs, algo.gp, algo.gmp]
refresh: monthly_incremental
algo_versions: {algo.gp: 3, algo.gmp: 3}
indexes: [[month], [channel_code, month]]
```

**验收**
- [ ] 桶内 `algo_version` 与算法注册表一致
- [ ] 增量刷新不破坏已有数据（`CONCURRENTLY` 可用）
- [ ] 算法升级后仅重算受影响桶

## M-RULE · 规则引擎模块

| 项 | 内容 |
|---|---|
| 语言 | Rust |
| 职责 | 管理口径、费率、阈值、时间生效规则、fail-closed 判定 |
| 输入 | `rules/*.yaml` |
| 输出 | 求值后的 `RuleSet` |
| 依赖 | — |

**能力**
- 时间生效：`effective_from` / `effective_to`，同一规则可多版本共存
- 作用域：`{platform, country, brand, channel}` 组合匹配
- 优先级：具体 > 通用；冲突时 DENY 优先

**验收**
- [ ] 同一规则多版本按生效时间正确选择
- [ ] 规则覆盖率可查询（哪些数据没有规则）
- [ ] 费率变更后受影响的桶被标记 stale

## M-RENDER · 渲染模块

| 项 | 内容 |
|---|---|
| 语言 | TypeScript |
| 职责 | 纯函数渲染：`DataContract` → DOM |
| 输入 | `DataContract`（**唯一入参**） |
| 输出 | 组件树 / DOM |
| **禁止** | 不含业务计算；不读 `QueryState`；不发查询请求 |
| 依赖 | 主题 token |

**默认收起契约**（硬性）

```ts
export const DEFAULT_EXPANDED = { L0: true, L1: false, L2: false, L3: false, L4: false };
```

**验收**
- [ ] 同一 `DataContract` 渲染结果确定（纯函数）
- [ ] 所有可折叠表格初始 `open=false`（闸门断言）
- [ ] 缺值渲染为 `待接入` / `—`，不显示 `0`
- [ ] 无权字段不进 DOM

## M-GROUP · 用户分组（D12 新增）

| 项 | 内容 |
|---|---|
| 语言 | Go（后端）+ TypeScript（前端） |
| 职责 | 建组、管成员、组级授权、成员继承、生效预览（§08） |
| 契约 | `UserGroup` / `GroupMembership` |
| 详见 | `docs/08-分组与权限申请设计.md` §2 |

**关键规则**
- 一人多组，授权取并集；组不含层级
- 组授权与个人勾选冲突 → **DENY 优先**
- 成员可「退出继承」（局部排除）以处理例外
- 建组/改名/改授权/加人/移人 全部落审计

**验收**
- [ ] 可创建任意分组、批量增删成员、导出名单
- [ ] 组授权成员自动继承（并集），DENY 优先
- [ ] 「加入该组后能看到什么」即时预览
- [ ] 组授权可复用为命名套餐（§13.5）

## M-REQ · 权限申请流（D14 新增）

| 项 | 内容 |
|---|---|
| 语言 | Go（后端）+ TypeScript（前端） |
| 职责 | 申请单管理、审批路由、自动开通、到期回收（§08） |
| 契约 | `PermissionRequest` |
| 详见 | `docs/08-分组与权限申请设计.md` §3–§4 |

**关键流程**
```
用户勾选数据权限 → 填用途/有效期 → 提交
  → 校验（是否超范围/去重）→ 路由审批人（职权覆盖链 D13）
  → 审批（同意/拒绝/退回）→ 通过则自动写入 Entitlement → 即时开通
  → 到期自动回收 + 留审计
```

**审批路由约束（D13）**
- 审批人必须**自身拥有**被申请的全部权限（`S ⊆ 权限(P)`）
- 上级权限不足 → 自动升级到最近的权限超集上级
- 越级/跨枝 → 最近公共上级；无则 T1 兜底
- IT 不可申请业务数值（D7）

**验收**
- [ ] 申请页以勾选树呈现，已拥有项置灰
- [ ] 审批人看到生效预览（"批了之后此人能看到什么"）
- [ ] 通过后 Entitlement 自动生效，无需 IT 手工配置
- [ ] 时间盒到期自动回收
- [ ] 代授/审批不溢出自身权限范围
- [ ] 全链路（申请→审批→开通→使用→回收）可审计

## M-AUTH · 权限模块（横切）

| 项 | 内容 |
|---|---|
| 语言 | Go |
| 职责 | RBAC + ABAC + **勾选式授权（D11）** + 分组授权（D12）+ 职权覆盖（D13）；行级列级裁决；脱敏 |
| 求值 | 模板起点 ⊕ 分组授权 ⊕ 逐项勾选 ⊕ 已批准申请 ⊕ 上级代授 ⊖ DENY（优先）⊕ 临时授权 |
| 输出 | `EntitlementView` → 按账号投影后的可见数据集 |
| 契约 | `contracts/entitlement.ts` |
| 详见 | `docs/07-账号权限勾选设计.md`、`docs/08-分组与权限申请设计.md` |

**勾选客体**：模块 / 数据维度（行级）/ 密级（列级）/ 逐字段覆写。

**核心不变量**：`可授出集合(账号 A) ⊆ 账号 A 自身权限集合`（防横向/纵向提权）。

**验收**
- [ ] 每个账号可逐项勾选模块与维度，不被固定模板锁死
- [ ] DENY 优先于启用；分组与个人冲突时取 DENY
- [ ] 勾选者/代授者授予范围不超过自身层级
- [ ] 勾选结果即时预览，且预览 == 服务端求值
- [ ] **IT 恒不可见业务数值**，`canViewBusinessValues` 恒 false 且不可勾选（D7=取消）
- [ ] 未走完审批的申请不生效（D14）
